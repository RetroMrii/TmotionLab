# TmotionLab current state — Reading Studio after P12, 2026-11-04

P11 research is complete. P12 integrates the frozen
`roberta_goemotions_rare4x_v001` seed-42 candidate into FastAPI and React.
Analyze is operational locally on CPU. The previous `project _state.md` is a
historical transition snapshot; `DAIR-MODEL-OLD/docs/project_state.md` describes
the original P0–P10 laboratory.

## Operational behavior

- API 0.4.0: `POST /v1/goemotions/predict`, schema version 1, 28 canonical labels,
  sigmoid scores, fixed threshold >= 0.25, zero/multiple detections and top-five
  ranking. Text limit 5000 characters; token limit 48 including special tokens.
- Load once per lifespan from local `best_model/`; verify frozen model and
  manifest hashes, mapping and a warm-up inference before advertising availability.
- CPU default, optional CUDA/auto with startup CPU fallback. No network download,
  retraining, threshold tuning, new research predictions or modifications to P11.
- `/health` and `/models` expose subsystem status and capabilities. Initialization
  failures are logged and isolated; unavailable routes return structured 503.
- React `/` and `/predict` both render Analyze with preserved input, request
  invalidation/cancellation, accessible status/errors, full-score disclosure and
  truncation notice. Neutral may co-occur; no unsupported contextual Interpret link.
- Historical DAIR `/metrics`, `/compare/{example_id}`, `/errors` and
  `/errors/confusions` work from archived offline artifacts: three models, 207
  TextCNN disagreements. The archive is unchanged.
- Legacy `/predict` and `/interpret` remain discoverable but unavailable because
  archived Python imports and paths no longer resolve. No RoBERTa attribution is
  claimed. Advanced UI pages identify their distinct DAIR provenance.
